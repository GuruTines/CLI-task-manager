# CLI Task Manager

Простое CLI-приложение на **Go** для управления задачами. Проект был создан в ознакомительных целях для закрепления практических навыков программирования и изучения возможностей языка.

## Возможности

- **Создание задач** — добавление новых задач.
- **Поиск задач** — поиск по различным критериям.
- **Комментарии** — добавление комментариев к выбранным задачам.
- **Редактирование** — изменение существующих задач.
- **Удаление** — удаление задач.
- **Фильтрация** — отбор задач по заданным критериям.
- **Статистика** — получение статистики по задачам.

## О проекте

Это один из моих первых проектов на Go, написанный в первую очередь для практики и закрепления полученных знаний.

На момент разработки приложение не имело строгого архитектурного разделения. Основной целью было попробовать себя в создании полноценного CLI-приложения, реализовать базовые операции с задачами и получить практический опыт.

Проект остался незавершённым, но стал частью моего пути в изучении Go.

## Запуск приложения
Для запуска приложения достаточно запустить файл main.go. В терминале вы видите меню со всеми функциями приложения.
При нажатии на каждую из них вам будут предложены инструкции к выбранной функции.
После каждого выбора меню отображается снова, пока вы не нажмете 0 (Выход).
